# UI/UX DESIGN PROMPT — AZAN SEEKHEIN

Design a complete, modern, premium Islamic learning feature called **“Azan Seekhein”** inside the **Quran Majeed App**.

The goal is to help Muslims learn, listen to, understand, and practice Azan step-by-step.

The design must feel like a **high-quality Quran/Islamic app**, not like a generic educational app.

## DESIGN STYLE

Create a clean, elegant, peaceful Islamic UI.

Design language:

* Minimal
* Premium
* Calm
* Spiritual
* Modern
* Highly readable
* Mobile-first
* Easy for children, adults, and elderly users

Use:

* Soft neutral backgrounds
* Elegant Islamic visual elements
* Subtle geometric Islamic patterns
* Beautiful Arabic typography
* Modern rounded cards
* Generous spacing
* Clear hierarchy
* Subtle animations
* Premium audio-player components

Do NOT make the interface overly decorative or crowded.

The Arabic text must always be the visual focus.

Support:

* Light Mode
* Dark Mode
* Urdu
* English
* Arabic

# UX RULES

1. Every screen must have ONE primary CTA.

2. Arabic must always have visual priority.

3. Keep the interface simple enough for elderly users.

4. Audio controls must be obvious.

5. Never autoplay audio unexpectedly.

6. Allow replay at any time.

7. When moving to the next phrase, automatically stop the previous audio.

8. Preserve user's learning progress.

9. If the user leaves halfway through a lesson, allow them to continue from where they stopped.

10. Use subtle animations only.

11. Keep Islamic visual elements elegant and minimal.

12. Support both Light Mode and Dark Mode.

13. Make the entire experience responsive for different mobile screen sizes.
